# 要件定義（v0.2 / 2026-11-22）

## 1. 目的

本機の名称は **7400sCCP8**（7400-series Complete Collection Processor、8bit）。

- 7400 シリーズ IC のコレクションを、棚に並べるだけでなく **CPU として動作する形**で持つ。
- 希少な IC（74x181 / 74x182 / 74x89 / 74x284 / 74x285 / 74x141 とニキシー管）に、外すと機能が欠ける実際の役割を与える。
- 手持ちの IC を可能な限り多種類使い、新しい型番が手に入ったら構成を差し替えられる。
- 配線と回路をユーザーが確認できるよう、回路図を生成する工程を持つ。
- 参考にする規模感: TD4（4bit）と TTM8（8bit・ロジック IC 44 個・16 命令・16 進キーパッドでプログラム入力）。

| 番号 | 決定 | 日付 |
|---|---|---|
| D1 | データ幅は 8bit。4bit スライス単位で構成する | 2026-11-22 |
| D2 | ALU は 74x181 × 2 + 74x182、データ RAM は 16 語 × 4bit の IC × 2 を使える前提とする | 2026-11-22 |
| D3 | リポジトリは `7400SeriesProcessor`（public・MIT）。`collection/` と `structures/` をサブモジュールにする | 2026-11-22 |
| D4 | ニキシー管表示は別基板に分離し、高圧は市販の昇圧モジュールを載せる前提で設計する | 2026-11-22 |
| D5 | 「多種類を使う」は、役割をスロットとして定義して同じ役割を別型番で実装した差し替えカードを増やすことを主とし、1 構成の中でも役割ごとに型番を使い分ける | 2026-11-22 |
| D6 | 構成変更の単位は役割カード（バックプレーンに挿す小基板）。ピン互換を一次資料で確認できた組だけ IC ソケット差し替えを併用する。カードは構成データからスクリプトで生成する | 2026-11-22 |
| D7 | 役割は core / peripheral / panel の 3 層すべてを「使用」に数える。ただし、外すと何かの機能が欠ける IC だけを載せる | 2026-11-22 |
| D8 | プログラムメモリは差し替え可能なスロットにする（実装は D21）。74 以外の IC はプログラム記憶・発振子・電源・高圧に限る | 2026-11-22 |
| D9 | 常用クロックは手動ステップ〜数十 Hz。上限は 100 kHz 程度とする | 2026-11-22 |
| D10 | 公開するのは構成に採用した実型番まで。購入先・入手メモ・購入予定・未採用の手持ちは載せない。手持ちとの照合はローカル専用スクリプトで行う | 2026-11-22 |
| D11 | 回路図生成工程を設ける。`card.json` を正本に、配線表・KiCad 回路図・SVG を生成する。pinspec の無い型番は生成しない | 2026-11-22 |
| D12 | カードを差し替えてもニーモニック（ADD / SUB / AND …）は固定する。FN の符号化は ALU カードごとの対応表でアセンブラが吸収し、カード固有の機能は生の FN 指定で使う | 2026-11-22 |
| D13 | カード間信号は 5 V 単電源・TTL レベルに統一する。カードの出力は TTL 入力を規定本数駆動できること。HC 入力で受ける箇所の HCT 化／プルアップ、オープンコレクタ出力のプルアップはカード内で完結させる（規定本数は Phase 2 で数値化） | 2026-11-22 |
| D14 | 役割カードはマザーボードに平置きで挿し、IC の天面が見える形にする。Specimen Tiles とは別規格とし、タイルは個体の単体試験治具として使う | 2026-11-22 |
| D15 | 第 1 弾の製作範囲は core 一式（マザーボード 1 枚 + core のカード）。peripheral / panel は後から足す | 2026-11-22 |
| D16 | ALU は下位・上位スライスで型番を揃える。RAM とレジスタはスライスごとに型番を変えてよい | 2026-11-22 |
| D17 | ニキシー管は IN-12 系を使う。桁数は 8 桁程度まで可。陽極の切り替えにはフォトカプラを使える | 2026-11-22 |
| D18 | ニキシー表示は既存の自作ドライバ基板 ND712Mk00 の回路構造（74x141 互換 IC 1 個 + フォトカプラによる陽極切り替えのダイナミック点灯。7 桁 + 小数点で点灯実績あり）を流用する | 2026-11-22 |
| D19 | 表示の走査は CPU と独立した発振器・走査カウンタ・桁選択デコーダで自動的に行う。桁ごとの BCD はレジスタファイル（4 語 × 4bit）2 個に持ち、8 桁分とする。`OUT 0`〜`OUT 3` が 2 桁ずつ書き込む | 2026-11-22 |
| D20 | 第 1 弾（D15）の予算上限は 35,000 円程度。微小部品は PCBA、ソケット・コネクタなど大きい部品は手はんだとする | 2026-11-22 |
| D21 | プログラムは TTM8 にならい、16 進キーパッドから書き換え可能なメモリへ入力する。DIP スイッチによる ROM は作らない | 2026-11-22 |
| D22 | 名称は「7400sCCP」（7400-series Complete Collection Processor）。末尾にデータ幅を付け、本機（8bit）は「7400sCCP8」とする | 2026-11-22 |
| D23 | キーパッド入力装置（ローダ）は 74 シリーズだけで組む（キーエンコーダ、番地カウンタ、桁送りレジスタ、チャタリング除去）。マイコンは使わない。panel 層の役割として数える | 2026-11-22 |
| D24 | プログラムメモリはバイト幅の SRAM 2 個（16bit 語）+ 電池バックアップ、256 語。スロットなので後から不揮発メモリのカードに差し替えられる | 2026-11-22 |
| D25 | ローダの番地・データ表示は 2 進 LED 列を基本とする。16 進 7 セグメント表示は後から足す装置カードにする | 2026-11-22 |

## 3. 設計案（未承認。`docs/ARCHITECTURE.md`）

| 番号 | 案 |
|---|---|
| A1 | 単一サイクル・ハーバード構成のアキュムレータ機（A レジスタ、PC 8bit、フラグ C・Z） |
| A2 | 命令語 16bit（OP 4 / FN 4 / OPERAND 8）。ALU 系命令の FN は 74x181 の機能選択 S3..S0 にそのまま渡す |
| A3 | I/O は入力 16 ポート・出力 16 ポート。周辺装置カードはここに接続する |
| A4 | 74x89 の反転出力は読み出し側のインバータで戻す |

## 4. 未決事項

方針レベルの未決事項は無い（2026-11-22 の質疑で D1〜D25 を確定）。
残るのは一次資料の照合で決まる数値で、Phase 2 で確定する: 各 IC のピン配置、プルアップ抵抗値、D13 のファンアウト本数、カードごとの消費電流、ニキシー管の陽極抵抗と走査周波数、SRAM の型番。
設計案 A1〜A4（3 章）はカードの回路図をユーザーが確認する段階で承認を取る。

## 5. リスク

| 番号 | 内容 | 対応 |
|---|---|---|
| R1 | 74x181 / 74x182 / 74x89 / 74x284 / 74x285 / 74x141 のピン配置・機能表・電気特性が未照合。`sim/ic74/` の動作モデルも照合前 | Phase 2 でデータシートを収集・目視照合し、pinspec を作ってからカード化する。モデルの `VERIFIED` を更新する |
| R2 | ロジックファミリの混在によるレベル不足・ファンアウト超過 | D13 の規格に沿ってカードごとに入出力を確認する |
| R3 | S-TTL の消費電流と発熱 | カードごとに電源電流を見積もり、電源容量とパスコンを決める |
| R4 | オープンコレクタ出力（74x89・74x284・74x285）と RAM の反転出力 | プルアップ値を速度（D9）とシンク電流から決める。A4 |
| R5 | ニキシー管の高圧による感電・ロジック破壊 | D4。高圧部の沿面距離、放電抵抗、カバーを表示基板の要件にする |
| R6 | バックプレーン配線の遅延・反射 | D9 で速度を抑える。クロックは 1 か所から配る |
| R7 | 希少 IC は予備が無い。実物で動作未確認のものがある | 全数ソケット実装。先にエミュレータで設計を固め、単体試験治具（Specimen Tiles）で個体を確認してから載せる。代替カード（例: RAM の別型番）を用意する |
| R8 | `collection/` が非公開のため、第三者は pinspec を取得できない | このリポジトリで照合した分は `hw/pinspec/` に置く。`sim/` と `docs/` は単独で成立させる |

## 6. 段階計画
