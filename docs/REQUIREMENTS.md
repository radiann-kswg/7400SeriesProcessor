# 要件定義（v0.1 / 2026-11-22）

## 1. 目的

- 7400 シリーズ IC のコレクションを、棚に並べるだけでなく **CPU として動作する形**で持つ。
- 希少な IC（74x181 / 74x182 / 74x89 / 74x284 / 74x285 / 74x141 とニキシー管）に、外すと機能が欠ける実際の役割を与える。
- 手持ちの IC を可能な限り多種類使い、新しい型番が手に入ったら構成を差し替えられる。
- 配線と回路をユーザーが確認できるよう、回路図を生成する工程を持つ。
- 参考にする規模感: TD4（4bit）と TTM8（8bit・ロジック IC 44 個・16 命令）。

## 2. 決定事項

| 番号 | 決定 | 日付 |
|---|---|---|
| D1 | データ幅は 8bit。4bit スライス単位で構成する | 2026-11-22 |
| D2 | ALU は 74x181 × 2 + 74x182、データ RAM は 16 語 × 4bit の IC × 2 を使える前提とする | 2026-11-22 |
| D3 | リポジトリは `7400SeriesProcessor`（public・MIT）。`collection/` と `structures/` をサブモジュールにする | 2026-11-22 |
| D4 | ニキシー管表示は別基板に分離し、高圧は市販の昇圧モジュールを載せる前提で設計する | 2026-11-22 |
| D5 | 「多種類を使う」は、役割をスロットとして定義して同じ役割を別型番で実装した差し替えカードを増やすことを主とし、1 構成の中でも役割ごとに型番を使い分ける | 2026-11-22 |
| D6 | 構成変更の単位は役割カード（バックプレーンに挿す小基板）。ピン互換を一次資料で確認できた組だけ IC ソケット差し替えを併用する。カードは構成データからスクリプトで生成する | 2026-11-22 |
| D7 | 役割は core / peripheral / panel の 3 層すべてを「使用」に数える。ただし、外すと何かの機能が欠ける IC だけを載せる | 2026-11-22 |
| D8 | プログラムメモリは ROM スロットにする。最初はスイッチ ROM カード、実用は EEPROM カード。74 以外の IC はプログラム記憶・発振子・電源・高圧に限る | 2026-11-22 |
| D9 | 常用クロックは手動ステップ〜数十 Hz。上限は 100 kHz 程度とする | 2026-11-22 |
| D10 | 公開するのは構成に採用した実型番まで。購入先・入手メモ・購入予定・未採用の手持ちは載せない。手持ちとの照合はローカル専用スクリプトで行う | 2026-11-22 |
| D11 | 回路図生成工程を設ける。`card.json` を正本に、配線表・KiCad 回路図・SVG を生成する。pinspec の無い型番は生成しない | 2026-11-22 |

## 3. 設計案（未承認。`docs/ARCHITECTURE.md`）

| 番号 | 案 |
|---|---|
| A1 | 単一サイクル・ハーバード構成のアキュムレータ機（A レジスタ、PC 8bit、フラグ C・Z） |
| A2 | 命令語 16bit（OP 4 / FN 4 / OPERAND 8）。ALU 系命令の FN は 74x181 の機能選択 S3..S0 にそのまま渡す |
| A3 | I/O は入力 16 ポート・出力 16 ポート。周辺装置カードはここに接続する |
| A4 | 74x89 の反転出力は読み出し側のインバータで戻す |

## 4. 未決事項

| 番号 | 論点 | 推奨（未承認） |
|---|---|---|
| O1 | カードを差し替えても命令セットを固定するか | ニーモニック（ADD / SUB / AND …）を固定し、FN の符号化は ALU カードごとの対応表で吸収する |
| O2 | カード間信号の電気規格 | 5 V 単電源・TTL レベルに統一。カードの出力は TTL 入力を規定本数駆動できること、HC 入力で受ける箇所は HCT かプルアップをカード内に持つこと |
| O3 | カードの寸法・コネクタと Specimen Tiles との関係 | Specimen Tiles とは別規格の役割カードにする（タイルは 1 ピン 1 スイッチ／LED の展示用で、バス接続を持たない） |
| O4 | 基板の枚数と予算 | 未検討 |
| O5 | 8bit の下位・上位スライスで型番を揃えるか | ALU は揃える（桁上げ先見の条件を合わせる）。RAM・レジスタは変えてよい |
| O6 | 本機の名称 | 未検討 |
| O7 | ニキシー管の管種と桁数 | 4 桁（OUT 0・OUT 1 の 2 ポート）を仮定 |

## 5. リスク

| 番号 | 内容 | 対応 |
|---|---|---|
| R1 | 74x181 / 74x182 / 74x89 / 74x284 / 74x285 / 74x141 のピン配置・機能表・電気特性が未照合。`sim/ic74/` の動作モデルも照合前 | Phase 2 でデータシートを収集・目視照合し、pinspec を作ってからカード化する。モデルの `VERIFIED` を更新する |
| R2 | ロジックファミリの混在によるレベル不足・ファンアウト超過 | O2 の規格を決め、カードごとに入出力を確認する |
| R3 | S-TTL の消費電流と発熱 | カードごとに電源電流を見積もり、電源容量とパスコンを決める |
| R4 | オープンコレクタ出力（74x89・74x284・74x285）と RAM の反転出力 | プルアップ値を速度（D9）とシンク電流から決める。A4 |
| R5 | ニキシー管の高圧による感電・ロジック破壊 | D4。高圧部の沿面距離、放電抵抗、カバーを表示基板の要件にする |
| R6 | バックプレーン配線の遅延・反射 | D9 で速度を抑える。クロックは 1 か所から配る |
| R7 | 希少 IC は予備が無い。実物で動作未確認のものがある | 全数ソケット実装。先にエミュレータで設計を固め、単体試験治具（Specimen Tiles）で個体を確認してから載せる。代替カード（例: RAM の別型番）を用意する |
| R8 | `collection/` が非公開のため、第三者は pinspec を取得できない | このリポジトリで照合した分は `hw/pinspec/` に置く。`sim/` と `docs/` は単独で成立させる |

## 6. 段階計画

| 段階 | 内容 | 完了条件 |
|---|---|---|
| Phase 0 | 設計基盤（本書、アーキテクチャ草案、スロット定義、エミュレータ骨格、回路図生成工程） | テスト通過、実証カード 1 枚の回路図生成 |
| Phase 1 | 未決事項 O1〜O7 の確定、命令セット確定、サンプルプログラム拡充 | エミュレータ上で乗算 → BCD → ニキシー表示が動く（達成済み）。O1〜O7 が D になる |
| Phase 2 | 希少 6 型番の一次資料照合と pinspec、core の全カードの `card.json` と回路図、カード間インタフェース定義 | 全 core カードで検査警告 0・ERC 0、ユーザーの目視確認 |
| Phase 3 | 基板化（バックプレーン、カード、表示基板）、DRC、発注ゲート | DRC 0、発注チェックリスト全項目 |
| Phase 4 | 実機の組み立てと動作確認、peripheral / panel カードの追加 | デモプログラムが実機で動く |
